Why ZerFi?

Purpose-built for Android Termux — no bloat, just results.

Pixie Dust Attack

Automated WPS Pixie Dust attack that recovers WPA/WPA2 passwords by exploiting weak PIN algorithms.

Online Brute-force

Dictionary-based online WPS brute-force with support for custom PIN lists and session resume.

Auto-Exploit Mode

One-pass scanner that automatically selects the best attack vector for each target network.

Signal Analysis

Analyzes signal strength before attack to filter weak targets, maximizing success rate.

Router Database

Built-in database of Pixie Dust vulnerable router models; query any model on the fly.

HTML Reports

Generate detailed HTML penetration test reports with full session data and results.

Prerequisites

Before installing, ensure your device meets these requirements:

  • A rooted Android device (required for monitor mode).
  • Termux application installed from F-Droid or GitHub.
  • At least 500MB of free storage space.

Installation

ZerFi v2.0 installs globally — run it from anywhere.

Method 1: One-Command Install

Quickest way — paste this into Termux:

curl -sLo installer.sh https://raw.githubusercontent.com/ZeronModz/ZerFi/main/installer.sh && bash installer.sh

Method 2: Manual Install

Clone and set up step-by-step:

pkg update && pkg upgrade -y pkg install root-repo git tsu python wpa-supplicant pixiewps iw -y git clone https://github.com/ZeronModz/ZerFi cd ZerFi chmod +x install.sh bash install.sh

Troubleshooting & Tips

If you run into issues, follow these guidelines:

  • Turn off WiFi on your device before starting the tool.
  • Enable Mobile Hotspot — this prevents Android from interfering with wlan0.
  • If you see "Device or resource busy (-16)", toggle WiFi off and back on.
  • Disable GPS/Location if scanning or authentication fails.
